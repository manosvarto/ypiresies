# Υπηρεσίες

Πρόγραμμα υπηρεσιών για κινητό: ονόματα, εξαιρέσεις (άοπλοι, βάρδιες, άδειες), υπηρεσίες & ωράρια,
ημερήσιο ή εβδομαδιαίο πρόγραμμα με δίκαιη σειρά, και κατέβασμα σε Excel.

**Άνοιγμα:** https://manosvarto.github.io/ypiresies/

**Για υπολογιστή (Windows 10/11, Windows 7 32/64-bit):** https://manosvarto.github.io/ypiresies/pc.html
(χωρίς εγκατάσταση, η Python είναι μέσα στο .exe)

**Στο iPhone σαν εφαρμογή:** άνοιξε τη διεύθυνση στο Safari → κουμπί κοινοποίησης → «Προσθήκη στην οθόνη Αφετηρίας».
Μετά ανοίγει από το εικονίδιο, σε πλήρη οθόνη, και χωρίς ίντερνετ.

Τα ονόματα και το ιστορικό μένουν **μόνο στο κινητό** που τα έβαλε: δεν ανεβαίνουν πουθενά.
[Πολιτική απορρήτου](https://manosvarto.github.io/ypiresies/privacy.html)

Ανεπίσημη εφαρμογή: δεν είναι επίσημη εφαρμογή του Ελληνικού Στρατού, του ΓΕΣ ή του Υπουργείου Εθνικής Άμυνας
και δεν συνδέεται με αυτούς. Οι προτεινόμενες υπηρεσίες είναι γενικό παράδειγμα· κάθε μονάδα βάζει τις δικές της.

Τα αρχεία αυτά βγαίνουν αυτόματα από τον κώδικα της εφαρμογής. Άδειες λογισμικού: [LICENSES.txt](LICENSES.txt).
