Υπηρεσίες για υπολογιστή

Πρόγραμμα υπηρεσιών - ημερήσιο ή εβδομαδιαίο, δίκαιη σειρά για όλους

Κατέβασμα

⬇ Windows 10 / 11 64-bit ⬇ Windows 7 / 8 64-bit · παλιά μηχανήματα ⬇ Windows 7 / 8 32-bit · πολύ παλιά μηχανήματα

Δεν ξέρεις ποιο; Πίνακας Ελέγχου → Σύστημα → «Τύπος συστήματος» (32-bit ή 64-bit). Οι εκδόσεις για Windows 7 δουλεύουν και σε Windows 10/11.

Εγκατάσταση (δεν χρειάζεται)

  1. Δεξί κλικ στο zip → «Εξαγωγή όλων».
  2. Άνοιξε τον φάκελο «Υπηρεσίες» και κάνε διπλό κλικ στο Υπηρεσίες.exe.
  3. Αν βγει «Τα Windows προστάτευσαν τον υπολογιστή σας»: «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε» (βγαίνει σε κάθε πρόγραμμα που δεν έχει ψηφιακή υπογραφή).
  4. Δοκίμασε με το «Ονόματα_δείγμα.xlsx» ή διάλεξε το δικό σου Excel με τα ονόματα. Το κουμπί «Οδηγίες» έχει όλα τα υπόλοιπα.

Python δεν χρειάζεται. Η σωστή Python είναι ήδη μέσα στο .exe (3.12 για Windows 10/11, 3.8 για Windows 7). Δουλεύει 100% χωρίς ίντερνετ: πέρασέ το με USB σε υπολογιστή χωρίς δίκτυο.

Τι χρειάζεται

Σε πολύ παλιά Windows 7 χωρίς ενημερώσεις, αν βγει μήνυμα για «KB2533623», χρειάζεται αυτή η ενημέρωση της Microsoft. Για να ανοίξεις τα αρχεία που βγάζει χρειάζεσαι Excel ή LibreOffice.

Σημαντικό

  • Ανεπίσημη εφαρμογή: δεν είναι επίσημη εφαρμογή του Ελληνικού Στρατού, του ΓΕΣ ή του Υπουργείου Εθνικής Άμυνας και δεν συνδέεται με αυτούς.
  • Το πρόγραμμα που βγάζει είναι πρόταση: το ελέγχει και το εγκρίνει ο αρμόδιος. Δίνεται «ως έχει», χωρίς εγγύηση.
  • Δεν στέλνει τίποτα στο ίντερνετ: όλα μένουν στον φάκελο του υπολογιστή σου. Πολιτική απορρήτου · Άδειες λογισμικού
  • Οι προτεινόμενες υπηρεσίες είναι γενικό παράδειγμα. Κάθε μονάδα βάζει τις δικές της (ή ανεβάζει το δικό της άδειο έντυπο).
